# Interval

A fictional event registration demo recovered from the original `javaScript/eventRegistrationApp`. The managed API validates and discards submissions; it does not create accounts, bookings, emails or database records. Community charts use the original fixed example statistics.

## Design

An electric festival poster: acid yellow, hot pink, cobalt and ink; oversized condensed typography; stacked event bands; optical rings; and a perforated ticket-style form. The artwork uses native CSS, a locally bundled Anton display font and system body fonts, with no paid assets, remote font requests or design library dependencies. The motion control pauses the decorative rings, and the operating system's reduced-motion setting disables animation automatically.

The responsive layout retains the existing form fields, fictional autofill, validation, chart categories, sample data and discard-only API behavior. Labels, keyboard focus states, a skip link, semantic landmarks and live result messages remain available. Mobile layouts stack the ticket fields and keep all controls usable without horizontal scrolling.

See [managed deployment notes](../DEPLOYMENT.md) for infrastructure and API checks.

Anton is bundled unchanged from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/anton), under the SIL Open Font License 1.1. The original license is included in `site/fonts/OFL.txt`; no third-party font service is contacted.
